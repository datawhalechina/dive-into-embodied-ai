# Artículos e investigación

Parte de una pregunta de investigación y sigue los enlaces al artículo, al proyecto de sus autores y a las explicaciones del sitio. Las primeras entradas acompañan tutoriales existentes; se añadirán locomoción, percepción y modelos del mundo.

## Imitación y generación de acciones \{#imitation-learning}

### ACT · Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware \{#act}

**2023 · Manipulación bimanual / imitación / bloques de acciones**

Estudia cómo aprender manipulación precisa con hardware bimanual de bajo coste. ACT predice secuencias de acciones y aborda los errores acumulados en tareas largas de imitación.

- Fuentes: [artículo](https://arxiv.org/abs/2304.13705) · [proyecto](https://tonyzhaozh.github.io/aloha/)
- Aprende: [arquitectura y mecanismos de ACT](/docs/foundations/vla/act_action_chunking)
- Prueba: [entrenamiento bimanual ACT](/docs/practices/vla/act)

### Diffusion Policy · Visuomotor Policy Learning via Action Diffusion \{#diffusion-policy}

**2023 · Políticas visuomotoras / difusión / acciones continuas**

Modela la generación de acciones como eliminación de ruido condicionada para representar distribuciones multimodales. Combina información visual con ejecución de horizonte deslizante.

- Fuentes: [artículo](https://arxiv.org/abs/2303.04137) · [proyecto](https://diffusion-policy.cs.columbia.edu/)
- Aprende: [modelado de acciones con Diffusion Policy](/docs/foundations/vla/diffusion_policy)

## Modelos de visión, lenguaje y acción \{#vla}

### OpenVLA · An Open-Source Vision-Language-Action Model \{#openvla}

**2024 · VLA / datos de varios robots / ajuste fino**

Conecta un modelo de visión-lenguaje con predicción de acciones y publica modelo y código de entrenamiento para estudiar aprendizaje entre tareas y adaptación a nuevos robots.

- Fuentes: [artículo](https://arxiv.org/abs/2406.09246) · [proyecto](https://openvla.github.io/)
- Aprende: [reproducción y decisiones de ingeniería de OpenVLA](/docs/foundations/vla/openvla_engineering)
- Relacionados: [conjuntos de datos](./datasets) · [proyectos abiertos](./open-source)
