# ROS2

Questo tutorial collega cinematica, sviluppo ROS2 e pianificazione MoveIt 2 attraverso un braccio a due segmenti funzionante. Si rivolge a chi vuole costruire ed eseguire un sistema robotico, dalle equazioni all'applicazione completa.

![Un braccio a due segmenti pianifica un movimento con un ostacolo in RViz2](@site/docs/foundations/robotics-and-ros2/figs/full_system_small_demo.gif)

</Figure>

La dimostrazione finale mostra l'effettore che segue una traiettoria pianificata con ROS2 Jazzy e MoveIt 2.

## 1. Perché seguire questo tutorial \{#1-为什么学习这套教程}

Conoscere i singoli concetti è spesso più facile che collegarli. Il tutorial affronta tre passaggi:

- **Dalla matematica al software**: derivare FK/IK e implementare funzioni riutilizzabili.
- **Dai nodi al sistema**: combinare Topic, Service, Action, parametri e file Launch.
- **Dai modelli alla pianificazione**: integrare tf2, URDF e MoveIt 2.

## Preparare l'ambiente \{#环境准备}

Il codice è incluso in `codes/foundations/robotics-and-ros2/ros_ws`. Il vecchio percorso `ros_learning` è obsoleto: **non serve un progetto separato con quel nome**. Consulta il [README del codice](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/codes/foundations/robotics-and-ros2/README.it.md) per dipendenze e istruzioni progressive.

Prepara Ubuntu 24.04 e ROS2 Jazzy seguendo la [lezione 1](/docs/foundations/robotics-and-ros2/course_introduction). I comandi usano Bash. Esegui le prime due righe solo se non hai già clonato il repository; altrimenti entra nella sua directory radice:

```bash
git clone https://github.com/datawhalechina/dive-into-embodied-ai.git
cd dive-into-embodied-ai

export ROS_WS="$(pwd)/codes/foundations/robotics-and-ros2/ros_ws"
echo "$ROS_WS"
```

L'output è un percorso assoluto, ad esempio `/home/yourname/dive-into-embodied-ai/codes/foundations/robotics-and-ros2/ros_ws`. Imposta `ROS_WS` in ogni nuovo terminale oppure aggiungi a `~/.bashrc` una riga `export ROS_WS="..."` con quel percorso. Immagini e video usano Git LFS; la [guida ai contributi](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/CONTRIBUTING.md) spiega come scaricare tutte le risorse.

## Codice di supporto \{#配套代码}

- `$ROS_WS/scripts/`: esempi autonomi delle lezioni 2–3. Installa NumPy; ROS non è necessario.
- `$ROS_WS/src/`: pacchetti degli esercizi, inizialmente vuota. Creali seguendo le lezioni.
- `$ROS_WS/reference/src/`: pacchetti di riferimento ricavati dal tutorial. Copia i singoli file secondo le istruzioni. Conserva `reference/COLCON_IGNORE` per evitare la scoperta di pacchetti duplicati.

| Pacchetto | Contenuto |
| --- | --- |
| `my_robot_basics` | Cinematica, nodi di base, parametri e tf2 (4–8) |
| `my_robot_interfaces` | Interfacce Service/Action personalizzate (6) |
| `my_robot_description` | URDF e file Launch di visualizzazione, inclusi i tag ros2_control della lezione 10 (9–10) |
| `my_robot_planner` | Client di pianificazione (10–11) |
| `my_robot_bringup` | File Launch del sistema (11) |

**Genera `my_robot_moveit_config` con MoveIt Setup Assistant nella lezione 10**: non è incluso. Il file `demo_sim.launch.py` della lezione è conservato separatamente in `$ROS_WS/reference/moveit/`, da copiare dopo aver generato la configurazione. Il [README del codice](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/codes/foundations/robotics-and-ros2/README.it.md) spiega come compilare le lezioni 4–9 prima degli esperimenti MoveIt.

I pacchetti di riferimento integrano le modifiche delle lezioni successive per il confronto. Gli esperimenti ROS, RViz2 e MoveIt richiedono Ubuntu / Jazzy; gli script matematici e i controlli statici non sostituiscono la verifica completa dell'esecuzione.

## Note d'uso \{#使用说明}

- Il tutorial usa ROS2 Jazzy su Ubuntu 24.04. Con un'altra distribuzione, sostituisci il nome a `jazzy`; i concetti fondamentali restano gli stessi.
- Le lezioni MoveIt 2 distinguono `MoveGroupInterface` in C++ da `moveit_py` in Python.
- Gli esempi di shell usano sempre `vim` per modificare i file.
