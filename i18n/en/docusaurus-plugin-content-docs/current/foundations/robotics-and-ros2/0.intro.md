# ROS2

This tutorial connects kinematics, ROS2 engineering, and MoveIt 2 planning through a working two-link arm example. It is for developers who want to assemble and run a robot system, from the equations to the complete application.

The final demonstration shows the end effector following a planned trajectory with ROS2 Jazzy and MoveIt 2.

## 1. Why study this tutorial \{#1-为什么学习这套教程}

Knowing individual concepts is often easier than connecting them. This tutorial addresses three gaps:

- **Math to engineering**: derive FK/IK and implement reusable functions.
- **Nodes to systems**: combine Topics, Services, Actions, parameters, and Launch files.
- **Models to planning**: integrate tf2, URDF, and MoveIt 2 into one planning system.

Introduction → Kinematics (2–3) → ROS2 engineering (4–7) → Frames and models (8–9) → MoveIt 2 (10–11) → Review (12)

## Environment setup \{#环境准备}

The companion code is included at `codes/foundations/robotics-and-ros2/ros_ws`. The old `ros_learning` path is obsolete; **no separate project of that name is needed**. See the [code README](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/codes/foundations/robotics-and-ros2/README.en.md) for dependencies and staged instructions.

Prepare Ubuntu 24.04 and ROS2 Jazzy following [lesson 1](/docs/foundations/robotics-and-ros2/course_introduction). The commands below use Bash. Run the first two lines only if you have not cloned the repository; otherwise enter its root directory:

```bash
git clone https://github.com/datawhalechina/dive-into-embodied-ai.git
cd dive-into-embodied-ai

export ROS_WS="$(pwd)/codes/foundations/robotics-and-ros2/ros_ws"
echo "$ROS_WS"
```

The output is an absolute path such as `/home/yourname/dive-into-embodied-ai/codes/foundations/robotics-and-ros2/ros_ws`. Set `ROS_WS` in each new terminal, or add an `export ROS_WS="..."` line with that absolute path to `~/.bashrc`. Images and videos use Git LFS; see the [contributor guide](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/CONTRIBUTING.md) for downloading all assets.

## Companion code \{#配套代码}

- `$ROS_WS/scripts/`: standalone examples for lessons 2–3. Install NumPy; ROS is not needed.
- `$ROS_WS/src/`: your exercise packages, initially empty. Create them as you follow the lessons.
- `$ROS_WS/reference/src/`: reference packages assembled from the tutorial. Copy individual files as instructed. Keep `reference/COLCON_IGNORE` to prevent duplicate package discovery.

| Package | Contents |
| --- | --- |
| `my_robot_basics` | Kinematics, basic nodes, parameters, and tf2 (4–8) |
| `my_robot_interfaces` | Custom Service/Action interfaces (6) |
| `my_robot_description` | URDF and visualization Launch files, including lesson 10 ros2_control tags (9–10) |
| `my_robot_planner` | Planning clients (10–11) |
| `my_robot_bringup` | System Launch file (11) |

**Generate `my_robot_moveit_config` with MoveIt Setup Assistant in lesson 10**; it is not bundled. That lesson's `demo_sim.launch.py` is stored separately in `$ROS_WS/reference/moveit/` for copying after configuration generation. The [code README](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/codes/foundations/robotics-and-ros2/README.en.md) explains how to build lessons 4–9 before moving on to MoveIt.

The reference packages incorporate changes from later lessons for comparison. ROS, RViz2, and MoveIt experiments require Ubuntu / Jazzy; math scripts and static checks do not replace full runtime validation.

## Usage notes \{#使用说明}

- The tutorial defaults to ROS2 Jazzy on Ubuntu 24.04. When using another distribution, substitute its name for `jazzy`; the core concepts remain the same.
- The MoveIt 2 lessons distinguish C++ `MoveGroupInterface` from Python `moveit_py`.
- Shell examples consistently use `vim` to edit files.
