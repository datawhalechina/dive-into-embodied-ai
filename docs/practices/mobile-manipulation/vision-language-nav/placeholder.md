# 视觉语言导航（VLN）实战

传统几何导航需要人工在地图上点击 `(x, y)` 坐标；而在真实家居或办公环境中，人更习惯说“**去客厅沙发旁边的红色积木那里停下**”。**视觉语言导航（Vision-and-Language Navigation, VLN）** 让机器人仅凭自然语言指令与第一视角视觉观测，在环境中自主探索、识别目标、绕开障碍并精准停靠。

## 1. 任务分类与核心评测指标 \{#metrics}

| 常见任务形态 | 输入指令示例 | 核心难点 |
| :--- | :--- | :--- |
| **ObjectNav（目标物导航）** | “找到厨房里的马克杯” | 跨房间语义常识推理、未见区域探索策略 |
| **VLN-CE（连续环境指令导航）** | “走出卧室右转，经过餐桌，停在落地灯前” | 长指令步骤对齐、历史记忆跟踪、连续避障 |
| **指令级避障与组合导航** | “绕过障碍物，走到蓝色方块旁” | 空间关系理解、局部反应式避障与停靠判定 |

评测导航策略不能只看“最后到没到”，标准基准（如 Habitat / HM3D / R2R-CE）普遍联合统计以下指标：

- **SR（Success Rate，成功率）**：最终停止位置与目标距离小于阈值（如 `1.0 m` 或近距离精确停靠阈值）的回合比例；
- **SPL（Success weighted by Path Length）**：按最短路径长度 $l_i$ 与实际行走路径 $p_i$ 加权：

$$\text{SPL} = \frac{1}{N}\sum_{i=1}^{N} S_i \frac{l_i}{\max(p_i, l_i)}$$

SPL 防止策略靠“满屋子瞎转碰运气”刷高成功率；
- **NE（Navigation Error）**：回合结束时到目标的欧氏距离；
- **OSR（Oracle Success Rate）**：整条轨迹中是否曾经路过目标——如果 **OSR 远高于 SR**，说明模型“看懂并走到了，但没学会在正确时机停下”（停靠判定问题是 VLN 最高频的失败模式之一）。

## 2. 两条主流技术路线对比 \{#architectures}

### 路线 A：分层语义导航（VLM + 语义地图 + 传统/RL 底层导航）
- **流程**：用开放词表检测/分割（如 GroundingDINO / SAM）或 VLM 提取关键帧语义，投影构建 2D/3D 语义代价地图或前沿探索点（Frontier）；VLM 根据语言指令选择下一个航点，交给 Nav2 或底层 RL 策略执行。
- **优势**：零样本泛化强、长距离跨房间不迷路、易于复用现成避障器；
- **局限**：链路长、依赖外参标定与深度精度、局部狭窄交互反应偏慢。

### 路线 B：端到端 / 轻分层 VLA 导航（图像 + 语言 → 速度/步态指令）
- **流程**：微调轻量 VLA 模型（如 SmolVLA 450M），直接从机载 RGB 图像与文本指令输出高层运动意图或离散/连续速度，交给稳定的底层步态控制器执行。
- **本仓库可复现实测案例 —— [Petoi Quaddle VLA 导航训练](/docs/practices/vla/quaddle/)**：
  - 架构：**SmolVLA 450M（高层视觉语言决策）+ 查表 CPG（低层稳定步态运控）**；
  - 算力门槛：**仅需 10 GB 显存**即可完成完整微调与闭环评估；
  - 实测能力阶梯与关键工程突破：
    - **Temporal Ensembling（时序集成）**：有效抑制单帧视角抖动引发的左右摇摆，将 L2 语言导航推进至 **90%**（20 回合评测）；
    - **任务分解（Task Decomposition）**：将复杂复合任务拆解为子目标，L3 绕障导航达 **80%**、L4 组合导航达 **85%**；
    - 完整实验记录（含阴性失败案例与 8.2× 训练加速缓存技巧）见 [Quaddle VLA 实验记录](/docs/practices/vla/quaddle/experiment-notes)。

## 3. 常见 VLN 失效分析与工程对策 \{#failure-modes}

1. **走到了却不停（高 OSR、低 SR）**：数据集中“移动帧”远多于“停止帧”，类别不平衡导致模型不敢输出停止动作——需在采集或采样时对停止过渡帧加权，或增加显式到达判定头。
2. **原地打转或反复横跳**：历史上下文窗口过短导致忘记刚刚探索过的方向——引入多帧历史图像缓存、动作块时序集成（Temporal Ensembling）或轻量化访问网格记忆。
3. **跨光照 / 跨仿真器视觉掉点**：在微调阶段加入亮度、色温、随机裁剪和相机倾角扰动增强，并尽量固定机载相机的真实内参与安装高度。
