# 零基础入门：先看路径，再动手做第一个项目

刚接触具身智能，可以先用 [学习地图](/learning-map) 建立全局认知，再通过一个完整项目把概念连接起来。

## 先看学习地图

[打开具身智能学习地图](/learning-map)：用抓取、行走和导航三个任务，理解感知、决策、控制与工程底座的关系，再选择入门路线和实践方向。

想系统了解这个领域，可以读 [具身导论](/docs/introduction/intro)：具身智能是什么、从哪里发展而来、机器人要完成哪些任务，以及还有哪些难题。

## 学习路径

- [学习路径](./learning-path)：从零基础到项目和求职的主线安排。

## 从0到1搭建四足机器人

建议先从一个完整项目建立“机器人系统是怎么拼起来的”的整体感：

- [从0到1搭建四足机器人](/docs/practices/quadruped/cs123/intro)：用 MuJoCo 从单关节 PD 控制一路搭到四足机器人和语言控制 demo。

## 下一步

入门阶段不追求把所有理论补完。先走完学习路径和第一项目，再进入 [理论技能树](/docs/foundations/intro) 按缺口补强化学习、控制、感知、仿真和数据工程。
