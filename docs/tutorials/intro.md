# 系列教程

围绕一个完整目标，沿着章节主线逐步学习和实现。适合希望有人带着走完一套流程、搭建完整系统的读者。

## 选择一套教程

| 教程 | 学习主线 | 前置知识 | 内容进度 |
| --- | --- | --- | --- |
| [从零到一搭建四足机器人](/docs/practices/quadruped/cs123/intro) | 执行器 → 运动学 → 四足建模 → 步态 → 策略训练 → 语言控制与感知 | Python 基础，按需补齐控制与线性代数 | 总览与 8 个章节可读 |
| [LeRobot 中文课程讲义](/docs/practices/robot-arm/data-collection/lerobot-course) | 机器人学习入门 → LeRobot 工具链 → 数据集 → 经典机器人学 | Python 基础 | 已整理 Unit 0–2；后续单元待补充 |

### 课程预告

[两轮足 Flamingo · Isaac Lab](/docs/practices/wheel-legged/flamingo-isaaclab/preview)：围绕两轮足机器人的平衡控制、强化学习训练与跨仿真验证展开。目前为课程预告，可先了解目标与学习准备。

## 怎么学

1. 先读课程总览，确认目标、环境与前置知识。
2. 按章节完成实验，保留自己的代码、参数和运行结果。
3. 遇到概念缺口时，到 [理论基础](/docs/foundations/intro) 查阅对应模块。
4. 完成主线后，到 [项目实战](/docs/practices/intro) 选择独立任务继续练习。

如果希望先体验一个具体效果，可以直接尝试 [MicroDuck 小黄鸭](/docs/practices/humanoid/microduck-rl) 或 [ACT 双臂操作](/docs/practices/vla/act)。查找原论文、数据和代码入口，请看 [具身信息](/docs/information/intro)。
