# 机械结构与执行器选型

算法最终要通过机械结构把力与位移作用到物理世界。理解机器人本体的自由度、传动链路、执行器特性与质量分布，不仅决定真机选型，也直接影响仿真建模（URDF / MJCF）、奖励设计与 Sim2Real 成败。

## 1. 构型与自由度（DoF）设计 \{#morphology-dof}

机器人本体的机械形态决定了它的工作空间、动力学特性和控制难度：

| 本体形态 | 典型自由度 | 物理特征 | 核心控制与学习难点 |
| :--- | :--- | :--- | :--- |
| **桌面机械臂** | 6–7 DoF（单臂）+ 1–2 DoF 夹爪 | 固定基座、刚性链、高精度位置闭环 | 碰撞回避、接触力控、长时程操作泛化 |
| **四足机器人** | 12 DoF（每腿 3 DoF：Hip Roll / Pitch + Knee） | 浮动基座、四点静态/动态支撑 | 复杂地形步态、足端打滑、外力抗扰动 |
| **两轮足 / 轮腿** | 6–8 DoF（腿部关节 + 轮毂电机） | 欠驱动倒立摆 + 轮式高速巡航 | 持续动态平衡、地形跃障与速度-姿态耦合 |
| **双足 / 人形** | 12 DoF（纯下肢）至 29–43+ DoF（全身含灵巧手） | 高重心、窄支撑多边形、多接触切换 | 高维协调、能量效率、摔倒恢复与全身操作 |

- **串联机构 vs 闭环连杆**：绝大多数工业机械臂与主流腿足采用串联运动学树（URDF 天然表达）；部分轻量化机器人（如 [Petoi Quaddle](/docs/practices/quadruped/quaddle-mujoco/) 或部分人形踝关节并联推杆）包含闭环四连杆，在 MuJoCo 中需要用 `<equality><connect>` 约束显式闭合。
- **质量集中原则（低腿部惯量）**：高动态腿足机器人会把大腿与小腿驱动电机尽量向髋部/躯干集中（通过连杆或同步带传递到膝关节），减小末端摆动惯量，使快速迈步和落地冲击更易控制。

## 2. 电机与减速器：执行器决定控制上限 \{#actuators}

机器人关节的核心是**电机 + 减速器 + 编码器 + 驱动器**的组合。不同传动比会带来截然不同的反向驱动能力（Backdrivability）与力控表现：

| 传动方案 | 典型减速比 | 优势 | 局限 | 典型应用 |
| :--- | :---: | :--- | :--- | :--- |
| **准直驱（QDD，外转子无刷 + 单级行星）** | `6:1 – 12:1` | 低反射惯量、高反向驱动性、抗冲击、可凭相电流估力矩 | 连续大扭矩发热高、断电无自锁 | Unitree Go2 / G1、MIT Cheetah、轮腿机器人 |
| **谐波减速器** | `50:1 – 160:1` | 零背隙、高重复定位精度、大减速比、结构紧凑 | 抗冲击弱、不可反向驱动、需外置力矩传感器 | 协作机械臂、部分工业人形上肢 |
| **舵机（总线伺服，如 Feetech / Dynamixel）** | `100:1 – 300:1` | 集成驱动与磁编码器、低成本、易接线 | 齿轮背隙、温漂、电压跌落与非线性摩擦明显 | SO-101、Pupper、MicroDuck、桌面教学平台 |

- **反射转子惯量（Armature）**：电机转子惯量 $J_m$ 经减速比 $N$ 折算到关节输出端会被放大 $N^2$ 倍（$J_{\text{ref}} = N^2 J_m$）。仿真中若漏填 MJCF 的 `armature`，策略在真机上极易抖动或发散。
- **电压跌落与高保真执行器建模**：低成本伺服在多关节同时发力时会出现电池压降、静态库仑摩擦与齿轮背隙（参考 [MicroDuck RL](/docs/practices/humanoid/microduck-rl/) 中的 BAM 执行器与背隙建模）。

## 3. 末端执行器与感知挂载 \{#end-effectors}

- **二指平行夹爪**：控制维度低（1 DoF）、耐用且易于模仿学习（如 ALOHA、SO-101），适合 80% 以上的抓放与桌面操作任务。
- **多指灵巧手（6–20+ DoF）**：支持手内旋转、工具使用与多指协同，但建模接触复杂、传感器与标定维护成本高。
- **传感器机械挂载**：相机（腕部第一视角 + 第三视角固定相机）、IMU 与 LiDAR 的支架刚度直接决定外参稳定性——柔性支架在高速迈步时会引发高频抖动和外参漂移（详见 [传感器标定与 sim2real](/docs/foundations/perception/sensor-calibration-sim2real)）。

## 4. 仿真建模与本体选型检查清单 \{#checklist}

把一台真实机器人准确搬进仿真（或选购教学/科研硬件）时，重点核对以下 6 项：

1. **质量与质心（Mass / CoM / Inertia）**：CAD 导出常遗漏电池、线束与计算板配重，导致实机前后倾偏置。
2. **关节限位与零位定义**：确认 URDF/MJCF 的关节正方向、软限位与实机编码器零点完全一致。
3. **峰值扭矩与转速包络**：用真实电机的扭矩-转速曲线限制仿真输出，避免策略学会“超物理”动作。
4. **控制与通信带宽**：明确底层总线（CAN / CAN-FD / 串口 / EtherCAT）支持的最高稳定闭环频率（参考 [CAN 与 MCU 通信](/docs/foundations/communication/can-mcu)）。
5. **维护与备件成本**：教学和算法验证优先选开源、易 3D 打印或标准化零件平台（如 SO-101、Pupper、MicroDuck）。
6. **碰撞体简化**：仿真物理碰撞尽量用胶囊、球体和长方体近似，视觉网格仅用于渲染，可显著提升并行吞吐并减少接触求解奇异。
