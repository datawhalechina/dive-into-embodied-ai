# ROS2

这套教程面向“想真正把机器人系统跑起来”的开发者：不只讲公式，也不只讲命令，而是围绕一个可运行的两连杆机械臂示例，串起运动学、ROS2 工程化与 MoveIt 2 规划闭环。

## 1. 为什么学习这套教程

在机器人开发里，常见问题不是“不会写代码”，而是“知识点会一点，但连不起来”。这套教程重点解决三个断层：

- **数学与工程断层**：把 FK/IK 从公式推导到可运行代码
- **单节点与系统断层**：把 Topic/Service/Action、参数、Launch 串成可维护工程
- **模型与规划断层**：把 tf2、URDF、MoveIt 2 接成一个完整规划系统

## 环境准备

配套代码随本仓库提供，目录是 `codes/foundations/robotics-and-ros2/ros_ws`。旧版说明中的 `ros_learning` 是旧路径，**无需另找或克隆同名项目**。代码入口、依赖和分阶段运行方法见[配套代码 README](https://github.com/datawhalechina/dive-into-embodied-ai/tree/master/codes/foundations/robotics-and-ros2)。

先准备 Ubuntu 24.04 + ROS2 Jazzy（见[第 1 讲](./1.course_introduction.md)）。以下命令使用 Bash；尚未克隆仓库时执行前两行，已有仓库则直接进入其根目录：

```bash
git clone https://github.com/datawhalechina/dive-into-embodied-ai.git
cd dive-into-embodied-ai

export ROS_WS="$(pwd)/codes/foundations/robotics-and-ros2/ros_ws"
echo "$ROS_WS"
```

输出应为本机工作空间的绝对路径，例如 `/home/yourname/dive-into-embodied-ai/codes/foundations/robotics-and-ros2/ros_ws`。以后打开新终端，也需要设置 `ROS_WS`；可将该绝对路径写入 `~/.bashrc` 的 `export ROS_WS="..."` 行。图片与视频使用 Git LFS，完整资源获取方式见[贡献指南](https://github.com/datawhalechina/dive-into-embodied-ai/blob/master/CONTRIBUTING.md)。

## 配套代码

- `$ROS_WS/scripts/`：第 2–3 讲的独立 Python 示例，安装 NumPy 后即可运行，无需 ROS。
- `$ROS_WS/src/`：自己的练习包，初始为空，按章节逐步创建。
- `$ROS_WS/reference/src/`：由教程示例整理的参考包，可按各章说明复制需要的文件。`reference/COLCON_IGNORE` 防止 colcon 重复识别参考包，请保留。

| 包名 | 内容 |
|------|------|
| `my_robot_basics` | 运动学函数、基础节点、参数和 tf2（4–8） |
| `my_robot_interfaces` | 自定义 Service/Action 接口（6） |
| `my_robot_description` | URDF、可视化 Launch，已包含第 10 讲的 ros2_control 标签（9–10） |
| `my_robot_planner` | 规划客户端节点（10–11） |
| `my_robot_bringup` | 一键启动 Launch 文件（11） |

`my_robot_moveit_config` **需要按第 10 讲通过 MoveIt Setup Assistant 生成**，不在参考包中预置。该讲的 `demo_sim.launch.py` 另存于 `$ROS_WS/reference/moveit/`，生成配置包后再复制。首次运行可按[配套代码 README](https://github.com/datawhalechina/dive-into-embodied-ai/tree/master/codes/foundations/robotics-and-ros2)先构建第 4–9 讲，再进入 MoveIt 实验。

参考包合并了后续章节的修改，适合对照学习；ROS、RViz2 和 MoveIt 实验需要 Ubuntu / Jazzy 环境，数学脚本与静态检查不能替代完整运行验证。


## 使用说明

- 文档默认使用 ROS2 Jazzy（Ubuntu 24.04），涉及其他发行版时把 `jazzy` 替换为对应名称即可，核心概念完全一致。
- MoveIt 2 章节中明确区分 C++ 的 `MoveGroupInterface` 与 Python 侧的 `moveit_py`，避免概念混淆。
- 所有 shell 命令示例统一使用 `vim` 编辑文件。
