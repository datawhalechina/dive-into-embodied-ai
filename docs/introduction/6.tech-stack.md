# 6. 技术栈

具身智能涉及从模型训练到机器人硬件的一整套技术。本章按八个技术方向介绍它们解决什么问题、包含哪些核心技术，以及对应的岗位。一个实际项目通常会用到其中多个方向。

## 6.1 大模型算法 \{#foundation-models}

大模型算法让机器人理解图像、语言与任务，并生成动作或预测环境变化。工作涉及模型设计、预训练、微调、后训练与评测。

**核心技术**：

- **多模态建模**：Transformer、视觉语言模型（VLM）、视觉语言动作模型（VLA），以及用于预测与规划的世界模型。
- **动作生成**：离散动作表示、扩散模型和流匹配。可以结合 [OpenVLA](https://openvla.github.io/)、[RDT](https://github.com/thu-ml/RoboticsDiffusionTransformer) 和 [π0](/docs/foundations/vla/pi0_foundation_model) 理解不同的动作表示与生成方式。
- **训练与后训练**：PyTorch / JAX、FSDP / DeepSpeed、多卡训练、数据配比、跨本体训练、模仿学习，以及利用交互反馈进行强化学习后训练。

**对应岗位**：具身大模型算法工程师、VLA 算法工程师、多模态算法工程师、世界模型算法工程师，以及机器人策略的强化学习后训练岗位。

站内学习：[VLA 概述](/docs/foundations/vla/vla-intro) · [OpenVLA 工程实践](/docs/foundations/vla/openvla_engineering) · [π0.6 在线学习](/docs/foundations/vla/pi06_online_learning)。

## 6.2 操作算法 \{#manipulation}

操作算法让机械臂、双臂或灵巧手完成抓取、搬运、装配、开门等任务，需要把物体感知、运动规划、策略学习和接触控制连接起来。

**核心技术**：

- **物体与抓取感知**：点云处理、分割、6D 位姿估计，以及 GraspNet / AnyGrasp 等抓取相关工作。
- **运动规划与控制**：正逆运动学、轨迹规划、碰撞检测、[MoveIt 2](https://moveit.picknik.ai/main/index.html)、阻抗控制与力控。
- **学习与灵巧操作**：ACT、Diffusion Policy、模仿学习、双臂协调，以及灵巧手动作重定向（retargeting），把人手或其他机体的动作映射到目标手的关节与约束中。

**对应岗位**：操作算法工程师、抓取算法工程师、机械臂算法工程师、灵巧操作算法工程师。以物体识别和位姿估计为主的工作，也会对应感知 / 3D 视觉算法岗位。

站内学习：[ACT 双臂训练](/docs/practices/vla/act) · [Diffusion Policy](/docs/foundations/vla/diffusion_policy) · [阻抗与力控制](/docs/foundations/controllers/impedance-force-control)。

## 6.3 运控算法 \{#motion-control}

运控算法负责机器人的平衡、行走、速度跟踪与全身协调，让动作在关节、力矩、接触和实时计算约束下稳定执行。常见方法包括学习型与模型型两条路线，也可以结合使用。

**核心技术**：

- **学习型运控**：[Isaac Lab](https://isaac-sim.github.io/IsaacLab/main/index.html)、MuJoCo、PPO、奖励设计、课程学习、域随机化、运动模仿与 sim2real。
- **模型型运控**：刚体动力学、模型预测控制（MPC）、全身控制（WBC）和数值优化，相关工具包括 Pinocchio、[OCS2](https://leggedrobotics.github.io/ocs2/) 与 CasADi。
- **真机执行**：状态估计、执行器建模、控制频率与时序、C++ / Python 实现，以及对延迟、噪声和模型误差的处理。

**对应岗位**：运动控制算法工程师、强化学习运控工程师、足式机器人控制工程师、人形机器人全身控制工程师。这里的 RL 主要优化运动与身体协调；VLA 的 RL 后训练侧重任务策略，两者的训练与部署条件不同。

站内学习：[PPO](/docs/foundations/rl-for-robotics/ppo) · [模型预测控制](/docs/foundations/controllers/mpc) · [MicroDuck RL](/docs/practices/humanoid/microduck-rl)。

## 6.4 导航 \{#navigation}

导航解决机器人在哪里、周围有什么、怎样到达目标的问题，涉及建图、定位、环境感知、路径规划、避障与失败恢复。

**核心技术**：

- **定位与建图**：激光 / 惯性方法如 FAST-LIO、LIO-SAM，视觉 / 惯性方法如 ORB-SLAM3、VINS，以及滤波、图优化、回环检测与重定位。
- **环境感知**：相机与激光标定、时间同步、点云处理、深度估计、可通行区域与障碍物识别。
- **规划与导航执行**：全局与局部路径规划、代价地图、ROS 2、tf2 和 [Nav2](https://docs.nav2.org/rolling/)；视觉语言导航（VLN）与语义导航还需要语言理解和语义地图。

**对应岗位**：导航算法工程师、SLAM 算法工程师、定位与建图算法工程师、机器人感知算法工程师，以及视觉语言导航相关岗位。

站内学习：[tf2](/docs/foundations/robotics-and-ros2/tf2) · [ODO、时间戳与状态估计](/docs/foundations/perception/odo-timestamps-state-estimation) · [传感器标定](/docs/foundations/perception/sensor-calibration-sim2real)。

## 6.5 仿真工程 \{#simulation}

仿真工程构建可训练、可测试、可复现的机器人环境，为算法开发、合成数据生成和真机验证提供支持。

**核心技术**：

- **仿真平台与资产**：Isaac Sim / Isaac Lab、MuJoCo，以及 USD、URDF、MJCF 等场景或机器人描述格式。
- **物理与传感器建模**：质量、惯量、摩擦、碰撞、接触、执行器与传感器模型，以及通过真实测量校准仿真的 real2sim。
- **规模化实验**：场景生成、域随机化、合成数据、并行仿真、性能分析和自动评测。涉及视频世界模型时，还需了解生成模型与动作条件预测。

**对应岗位**：仿真工程师、机器人仿真开发工程师、合成数据工程师、仿真评测工程师。世界模型的网络与训练方法开发通常对应世界模型算法岗位。

站内学习：[仿真工具概述](/docs/foundations/simulation/intro) · [MuJoCo](/docs/foundations/simulation/mujoco) · [世界模型](/docs/foundations/world-model/intro)。

## 6.6 数据工程 \{#data-engineering}

数据工程把遥操作、真机运行和仿真产生的数据，整理成可追踪、可训练、可复用的数据集，连接数据采集与模型训练。

**核心技术**：

- **采集与遥操作**：设备接口、遥操作系统、视频与机器人状态录制、观测和动作的时间对齐。
- **数据处理**：清洗、标注、掉帧与异常检测、数据格式、元数据与质量检查，记录本体、坐标系、单位、控制频率和标定版本。
- **数据平台**：Python、对象存储、任务调度、版本管理、数据集划分与高吞吐读取，以及 [LeRobot](https://huggingface.co/docs/lerobot/en/index) 等机器人学习工具链。

**对应岗位**：机器人数据工程师、数据平台工程师、数据质量工程师、遥操作系统工程师。数采操作岗位更侧重执行采集流程、设备操作与数据验收。

站内学习：[具身数据集](./resources/datasets.md) · [LeRobot 课程讲义](/docs/practices/robot-arm/data-collection/lerobot-course) · [SO-101 真机教程](/docs/practices/robot-arm/data-collection/so101-lerobot-real)。

## 6.7 部署工程 \{#deployment}

部署工程把感知、策略、控制器和硬件连接成稳定运行的系统，关注端到端延迟、资源占用、可靠性和故障恢复。

**核心技术**：

- **机器人软件**：C++、Python、Linux、ROS 2、DDS / QoS、设备驱动、多线程与进程间通信。
- **模型推理**：ONNX Runtime、TensorRT、量化、推理性能分析，以及 Jetson Orin 等端侧平台的计算、功耗和散热约束。
- **运行与维护**：实时调度、通信和推理时序、健康检查、日志回放、版本管理、部署回滚与安全停止。

**对应岗位**：机器人软件工程师、机器人系统工程师、模型部署工程师、推理优化工程师、机器人集成工程师。

站内学习：[ROS 2 工程基础](/docs/foundations/robotics-and-ros2/ros2_engineering_basics) · [控制器集成](/docs/foundations/controllers/integration) · [RTC 实时执行](/docs/foundations/vla/rtc_realtime_execution)。

## 6.8 硬件 \{#hardware}

硬件为机器人提供计算、感知、供电和运动能力，决定负载、速度、精度、续航与可靠性。不同部分对应不同的专业技术栈。

**核心技术**：

- **嵌入式**：C / C++、MCU、RTOS、中断、DMA、CAN / CAN-FD、SPI / I²C、传感器和执行器接口。
- **电机驱动**：FOC（磁场定向控制）、电流 / 速度 / 位置环、编码器、PWM、功率器件与保护电路。
- **电子**：原理图与 PCB、电源设计、信号完整性、EMC、热设计与板级测试。
- **机械与执行器**：CAD、机构学、材料与公差、有限元分析、电机与减速器选型、传动、装配和可靠性测试；灵巧手还涉及腱绳或连杆传动与触觉集成。

**对应岗位**：嵌入式工程师、电机驱动工程师、电子工程师、机械工程师、执行器工程师、灵巧手硬件工程师。

站内学习：[CAN 与 MCU 通信](/docs/foundations/communication/can-mcu) · [URDF 与机器人模型](/docs/foundations/robotics-and-ros2/urdf_and_rsp)。机械结构专题目前仍是[待完善入口](/docs/foundations/hardware/placeholder)。
