# 具身导论

:::tip 第一次来？先花 3 分钟上手
- 想先直观感受机器人控制：打开 [在线仿真](/simulation)，用键盘操控 7 台真实物理引擎机器人（无需安装）。
- 想直接选路线：回到首页的 [30 秒选路线](/#learning-paths)，按背景查看推荐的 3 步起点。
:::

具身导论用零数学、零编程门槛带你快速看清全局：具身智能是什么、机器人能做什么、难在哪里，以及该如何系统入门与求职。

## 怎样阅读 \{#how-to-read}

- **零基础入门**：先玩 3 分钟 [在线仿真](/simulation)，再读 1 → 3 → 4，随后到 [项目实战](/practices) 选一个标有「入门」的实验。
- **算法 / AI 背景**：读 1 → 2 → 5 把握核心挑战，再从 [项目实战](/practices) 切入模仿学习（ACT）或强化学习训练。
- **系统规划路线**：读 [6. 技术栈](./6.tech-stack.md)，按模块对照 [理论基础](/foundations) 与 [项目实战](/practices)。
- **求职与转行**：读 [7. 就业岗位](./7.careers.md)，了解岗位分工与准备重点。
- **查论文 / 数据 / 代码**：直接进入 [领域资源](./resources/index.md)。

导论不要求编程或数学基础。每章结尾均附站内延伸阅读，按需深入即可。
