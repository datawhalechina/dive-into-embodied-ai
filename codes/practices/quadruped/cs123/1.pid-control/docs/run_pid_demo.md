# Python 实时 PID 曲线实验

本实验使用 `run_pid_demo.py`、Python 和 Matplotlib，观察 PID 控制器如何让一个二阶被控对象跟踪目标值。程序会实时绘制目标值、过程值和控制输出，并允许在运行过程中动态调整 PID 参数。

环境准备请参见上级目录的 [README.md](../README.md)。

## 启动程序

在 `codes/practices/quadruped/cs123` 目录中运行：

```bash
uv run python 1.pid-control/run_pid_demo.py
```

## 界面说明

程序包含上下两幅实时曲线：

- 上图中的虚线是目标值，实线是被控对象的过程值。
- 下图显示 PID 控制器的输出，输出范围限制为 `0.0～2.0`。
- 图中右上角实时显示过程值、误差和控制输出。
- 曲线窗口显示最近 15 秒的数据。

界面底部提供以下控件：

- `Kp`：比例增益。
- `Ki`：积分增益。
- `Kd`：微分增益。
- `目标值`：动态改变控制器需要跟踪的目标。
- `暂停/继续`：暂停或恢复仿真。
- `复位`：清空曲线，并重置 PID 和被控对象的内部状态；当前滑块参数会被保留。

## PID 参数的作用

### Kp：比例项

比例项根据当前误差产生控制输出。

- 增大 `Kp` 通常会加快响应。
- `Kp` 过大可能导致明显超调或持续振荡。
- 只使用比例控制时，系统可能存在稳态误差。

### Ki：积分项

积分项累积历史误差，用于消除稳态误差。

- 增大 `Ki` 可以让过程值最终更接近目标值。
- `Ki` 过大可能增加超调，并使系统产生振荡。
- 实验中包含简单的积分抗饱和处理。

### Kd：微分项

微分项根据误差的变化速度提供阻尼。

- 适当增大 `Kd` 可以减小超调和振荡。
- `Kd` 过大会使控制输出对快速变化或测量噪声更加敏感。

## 建议实验

1. 将 `Ki` 和 `Kd` 调为 `0`，只改变 `Kp`，观察响应速度和稳态误差。
2. 缓慢增加 `Ki`，观察稳态误差如何逐渐消失。
3. 在出现超调后增加 `Kd`，观察振荡和超调是否减小。
4. 仿真稳定后突然改变目标值，观察不同 PID 参数下的跟踪效果。
5. 尝试较大的 `Kp` 和 `Ki`，观察输出限幅以及积分抗饱和的效果。

## 代码结构

- `PID`：实现离散 PID 计算、输出限幅和积分抗饱和。
- `SecondOrderPlant`：实验使用的二阶被控对象。
- `animate()`：按照固定时间步推进仿真，并刷新实时曲线。
- `Slider` 和 `Button`：提供参数调整、暂停和复位操作。

## 使用真实被控对象

当前的 `SecondOrderPlant` 是教学用数学模型，并不直接代表四足机器人关节。

接入 MuJoCo 关节或真实电机时，需要：

1. 使用关节位置或传感器测量值替代 `plant.value`。
2. 将 PID 输出发送到关节执行器，而不是调用 `plant.update()`。
3. 根据真实控制循环的执行周期设置 `DT`。
4. 按照执行器允许的力矩或控制量范围设置 `output_limits`。
5. 对微分项进行滤波，避免放大传感器噪声。
